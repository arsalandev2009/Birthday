Burhan Abdul Rehman's First Birthday invitation

Open index.html in any browser. Keep the three files in the same folder.

To change details:
- Date, time, venue, names: edit the text in index.html
- Countdown target: edit data-date on the #cd element in index.html (keep the +05:00 for Pakistan time)
- Colors and layout: style.css
- Balloons, countdown, RSVP behaviour: script.js

Fonts load from Google Fonts, so an internet connection is needed to see them.

Link preview (Open Graph):
- og-image.png (1200x630) is the picture shown when the link is shared on WhatsApp, Facebook, etc.
- In index.html, replace every https://your-domain.com with your real website address.
- Upload og-image.png to the same folder as index.html so the image link works.
- After going live, you can refresh old previews with the Facebook Sharing Debugger.
